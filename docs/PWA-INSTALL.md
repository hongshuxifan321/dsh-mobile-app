# 如何把 DSH Remote PWA 添加到主屏幕

PWA 可以像普通 App 一样添加到手机/电脑主屏幕，打开后全屏运行。

## iPhone / iPad（Safari）

1. 用 Safari 打开：
   ```
   https://hongshuxifan321.github.io/dsh-mobile-app/pwa/
   ```
2. 点击底部“分享”按钮
3. 选择 **“添加到主屏幕”**
4. 点右上角 **“添加”**

之后主屏幕会出现 DSH Remote 图标，点开即可使用。

## 鸿蒙 / 安卓（浏览器）

1. 用浏览器打开：
   ```
   https://hongshuxifan321.github.io/dsh-mobile-app/pwa/
   ```
2. 打开浏览器菜单（一般是右上角“···”）
3. 选择 **“添加到主屏幕”** 或 **“安装应用”**
4. 确认添加

## 电脑（Chrome / Edge）

1. 打开：
   ```
   https://hongshuxifan321.github.io/dsh-mobile-app/pwa/
   ```
2. 地址栏右侧会出现“安装”图标（或菜单里选“安装 DSH Remote”）
3. 点击安装

## 提示

- 第一次打开后建议刷新一次，确保加载最新版本
- 添加主屏幕后，打开的仍是同一个 PWA，数据不会丢失
