# DSH Remote — HarmonyOS 客户端（工程骨架）

> 当前是基础骨架，使用 ArkWeb 加载 DSH 网页。
> 需要用 DevEco Studio 打开本目录构建。

## 环境要求

- DevEco Studio 5.0+（HarmonyOS NEXT / API 12+）
- HarmonyOS SDK

## 使用步骤

1. 用 DevEco Studio 打开本目录（`harmonyos/`）
2. 等待工程同步完成
3. 修改 `entry/src/main/ets/pages/Index.ets` 中的 `url` 为你的服务器地址
4. 点击 Run 构建安装
